# ambierhq/homebrew-tap

Homebrew tap for [Ambier](https://ambierhq.com) open-source tools.

```sh
brew install ambierhq/tap/skigard
```

The `skigard` formula is not published yet. It will land here with the first release of
[skigard](https://github.com/ambierhq/skigard), a lockfile and review gate for agent skills.
