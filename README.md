# ambierhq/homebrew-tap

Homebrew tap for [Ambier](https://ambierhq.com) open-source tools.

```sh
brew install ambierhq/tap/skigard
```

The `skigard` formula is published here with each release of [skigard](https://github.com/ambierhq/skigard)
(currently `v0.1.1`): a lockfile and review gate for agent skills. The formula is updated by the skigard release
workflow; do not edit it by hand. Docs, threat model and what skigard does not protect against are in the skigard repository.
